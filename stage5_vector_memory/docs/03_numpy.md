## 这一课在向量里做什么

FAISS 要的不是 Python 列表，而是一块类型相同的连续数字。`vectors.py` 的 `as_float32_matrix` 用 `dtype=np.float32` 收成二维表。一行会补成只有一行的表，这样后面的「每一行」说法始终成立。

`l2_normalize` 用 `np.linalg.norm(..., axis=1, keepdims=True)` 得到每一行的长度。`keepdims=True` 让结果仍是一列，才能和原来的表逐行相除。长度是 0 的行不能除，函数把它留成全零。

除完之后，IndexFlatIP 的点积等于余弦。忘了这一步，字数多的段落会只因为数字大而排到前面。示例 4 会用 `[3, 4]` 和 `[0.6, 0.8]` 把这件事演出来。

## 常见坑

- 用 `view(np.float32)` 代替 `astype`。`view` 不换算，只是把同一块内存按更窄的格子重读，数字会乱。
- 以为当前这份 FAISS 接受 float64，就可以一直交 float64。这一版往往会帮你转成 float32。下一版不一定。写入前自己转。
- 全零行除以一个很小的数之后不再是零。`l2_normalize` 会把长度本来是 0 的行设回全零，避免「没有方向」变成一串灰尘。

## 练习

1. `(2,)` 和 `(1, 2)` 差在哪里？
2. `[3.0, 4.0]` 归一化后为什么是 `0.6` 和 `0.8`？
3. 全零向量归一化之后应该是什么？

## 答案

1. `(2,)` 是一维的两格。`(1, 2)` 是一张只有一行的表。FAISS 的 add 要的是二维表。
2. 长度是 5。3/5=0.6，4/5=0.8。方向不变，长度变成 1。
3. 全零。它没有方向，不能参与「谁和谁更像」。
