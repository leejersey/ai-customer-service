# 数字：整数和小数

`TEMPERATURE = 0.7` 里的 `0.7` 是小数。`MAX_TOKENS = 256` 里的 `256` 是整数。它们都没有引号。

## 先用一句人话

没有引号的数字可以拿来加减乘除。加上引号就变成文字，两个文字接在一起，不会按数学相加。

## 打个比方

`256` 是柜台上的 256 颗珠子，可以再添上 10 颗。`"256"` 是一张写着数字样子的纸条，和另一张纸条接起来，只是纸条变长，珠子并没有变多。

## 自己动手

```python
print(1 + 2)
print(0.7)
print(256)
max_tokens = 256
print(max_tokens - 6)
```

预期：

```text
3
0.7
256
250
```

文字相加不是数学：

```python
print("1" + "2")
print(1 + 2)
```

预期：

```text
12
3
```

第一行是两段文字拼接。第二行才是加法。

## 和我们脚本的关系

`0.7` 会原样放进发给模型的那份 JSON，字段名是 `temperature`。它不是「70%」，也不是「智能程度」。数字课只负责你认出它是数字。它在模型里的意思，导读讲到那一行时再说。

`256` 会放进 `max_tokens`。它限制模型这次新写的长度，不是限制你的问题有多长。这个区别也在导读里，不在本课。

## 常见错误

小数点写成中文的句号：

```python
temperature = 0。7
```

```text
SyntaxError: invalid character '。' (U+3002)
```

必须是英文句点 `.`。

整数中间加千分位逗号：

```python
print(1,000)
```

这不会报错，但 `print` 会以为你给了两样东西：`1` 和 `000`。预期变成：

```text
1 0
```

因为 `000` 就是 `0`。想表示一千，写 `1000`，不要写 `1,000`。

拿文字和数字相加：

```python
print("次数" + 3)
```

```text
TypeError: can only concatenate str (not "int") to str
```

`str` 是字符串，`int` 是整数。要显示在一起，用 `print("次数", 3)`，或等字符串课学 f-string。

## 练习

1. `print(10 / 2)` 的结果是什么？`print(10 - 3)` 呢？
2. 为什么 `MAX_TOKENS = "256"` 以后，如果有人写 `MAX_TOKENS - 1`，会出哪一类错误？（说出错误类型即可，不必背整句英文。）
3. `0.7` 和 `"0.7"` 哪一个是数字？

## 答案

1. `5.0` 和 `7`。除法在 Python 3 里得到小数，所以是 `5.0` 不是 `5`。
2. `TypeError`。减号左边变成了文字。
3. `0.7` 是数字。`"0.7"` 是文字。
