# 余弦相似度：方向像不像

[导入](08_import.md) 用 `math.sqrt(16)` 练过「点号到模块里面取函数」。那一课只说明导入。这一课说明阶段 4 为什么要开平方，以及为什么还用到 `math.log`。

阶段 4 用在 [检索](../stage4_rag/docs/03_retrieve.md) 的 `cosine` 和 `build_idf`。分数不是概率。`0.15` 不是「15% 的把握」。

## 先用一句人话

把每个词的权重当成一根箭头在各个方向上的分量。余弦看的是两根箭头朝向像不像，不看哪一根更长。完全同向接近 `1`，没有公共词就是 `0`。

## 打个比方

两个人在广场上各指一个方向。你问的是他们指得像不像，不是谁的胳膊更长。一段资料特别长，词特别多，胳膊就更长。如果不先除以长度，长文会只因为词多而赢过那句真正对上的短规定。

## 自己动手

```python
import math

def length(vector):
    total = 0.0
    for value in vector.values():
        total += value * value
    return math.sqrt(total)

def cosine(left, right):
    dot = 0.0
    for key in left:
        if key in right:
            dot += left[key] * right[key]
    return dot / (length(left) * length(right))

print(cosine({"退货": 3}, {"退货": 5}))
print(cosine({"退货": 1}, {"发票": 1}))
print(math.log(1))
```

预期：

```text
1.0
0.0
0.0
```

第一行：点积是 `3 * 5 = 15`，两根长度是 `3` 和 `5`，`15 / (3 * 5)` 是 `1`。倍数不一样，方向仍相同。

第二行：没有公共的键，点积是 `0`。

`math.sqrt` 是开平方。长度是「各分量平方之和，再开平方」。只把分量加起来，不是长度。

`math.log` 是自然对数。`log(1)` 是 `0`。阶段 4 的 IDF 写成 `math.log((总段数 + 1) / (出现段数 + 1)) + 1`。一个二字词若几乎每段都有，括号里接近 `1`，对数接近 `0`，加 `1` 之后权重只剩 `1`。很少见的词，括号里更大，权重更高。加 `1` 是为了分母不会是 `0`，也免得「每段都有的词」权重变成 `0`、把句子里的字全丢掉。

空的向量没有方向。阶段 4 在除法之前先看长度是不是 `0`，是的话分数直接是 `0`，避免 `ZeroDivisionError`。

## 常见错误

把余弦当成百分比。`0.45` 的意思是「比 `0.10` 更同向」，不是做对了 45 道题里的百分比。阈值 `0.15` 是对着这批文档试出来的一道门，不是概率。

忘了除以两根长度。那只是点积。长段的点积容易更大，检索会被长文霸占。

`sqrt` 没写 `math.`。只 `import math` 时，名字 `sqrt` 还不存在。要么 `math.sqrt`，要么 `from math import sqrt`。第 8 课讲过这两种导入。

## 练习

1. 两个向量的键完全相同、数值互为倍数，余弦接近多少？
2. 没有公共词时，余弦是多少？为什么还要看长度？
3. `math.log(1)` 是多少？IDF 最后为什么还要 `+ 1`？

## 答案

1. 接近 `1`。方向相同。
2. 点积是 `0`，所以余弦是 `0`。长度用在有公共词的时候：把「词多所以数字大」除掉，留下方向。
3. `0.0`。`+ 1` 让每段都出现的词还留着一点权重，并且公式在出现段数为 `0` 时也不会去算 `log(0)`。阶段 4 根本不会把出现段数为 `0` 的词放进词表。

这一课是目前基础课的最后一课。阶段 4 的检索会把这些式子用在二字词上。
