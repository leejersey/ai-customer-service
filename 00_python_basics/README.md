# Python 基础课

这是一门单独的课，放在所有阶段前面。它不讲客服机器人怎么设计，只讲读后面代码时会撞上的 Python。

32 课都在这个目录里。阶段 0 用得到的、阶段 1 才用得到的，都在这里，不散落在各个 `stage*` 文件夹里。阶段文档只在概念第一次出现时给你链接，不把同一课再讲一遍。

每一课都有：人话解释、比方、要你亲手敲的例子和预期输出、常见报错原文、两三道练习和答案。课和课之间用文件名互相链接。这些链接只在本目录内部，换阶段目录时不用改它们。

## 两条学法

**零基础，想先把语法铺开：** 按课号从 [01](01_terminal.md) 读到 [32](32_accuracy.md)。课号就是推荐顺序。第 24 课之前，阶段 0 的脚本就会用到；第 24 课往后主要是阶段 1 才用到，可以留到阶段 1 导读叫停时再读，也可以现在读完。

**想边做客服边查：** 先做完下面三课（没有它们，后面的例子没有地方敲），然后打开 [阶段 0 导读](../stage0_basics/docs/README.md)。导读里看到「👉 不懂……？先看基础课」就进来做那一课，做完回到原来那一行。阶段 1 及以后同样办。

动手前的三课，按这个顺序：

1. [终端：cd、ls、路径](01_terminal.md)
2. [`.py` 文件，以及 `python 文件.py` 在做什么](02_py_file.md)
3. [`print`：让程序把字显示出来](03_print.md)

同一章里的课号不一定连着。例如「模块与 import」里是第 8 课和第 26 课：第 8 课在阶段 0 就要用，第 26 课要等阶段 1 跨文件夹时才用。查概念进章节，从头学按课号。课号不按章节重排，是为了每一课里写的「下一课」仍然指得对。

大模型用词（token、温度、流式）不在这门课里。去阶段 0 的 [名词表](../stage0_basics/docs/glossary.md)。

## 和阶段文档怎么配合

阶段 0、阶段 1 的导读开头各有一份「本阶段需要的基础课」。读阶段代码时以那份清单为入口，点进上面某一课。

以后新增的基础概念，加在这门课里，归进上面某一章，并在本章表格补一行：学什么、哪些阶段会用到。阶段文档只加链接，不另起一份语法讲义。这条规则也写在仓库根目录的 [README](../README.md) 里。
