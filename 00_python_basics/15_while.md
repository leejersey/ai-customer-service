# while、break、continue：不知道要重复几次的时候

`for` 适合「这一叠有几张就做几次」。命令行客服不知道顾客要说几句，所以用：

```python
while True:
    user_text = input("你：").strip()
```

## 先用一句人话

`while` 先问条件。条件为真，就把缩进的一块做完，然后回去再问一次。`while True` 的条件永远为真，所以不会自己停。必须在里面用 `return` 离开函数，或用 `break` 离开循环。

## 打个比方

`for` 是按今天手里的一叠信逐封处理，处理完就下班。`while True` 是柜台一直开着：来一位客人办一位。没有「打烊」这个口令，柜台就永远不关。`退出` 就是打烊口令。

`continue` 是「这位客人的事到此为止，去叫下一位」，柜台还开着。不要用它来打烊。

## 自己动手

```python
n = 0
while n < 3:
    n = n + 1
    print(n)
print("停了")
```

预期：

```text
1
2
3
停了
```

每一轮都把 `n` 加 1。忘了加，`n < 3` 永远成立，这就是死循环。终端里按 Ctrl+C 可以打断。你会看到 `KeyboardInterrupt`。我们的客服脚本把这个打断接住，改成打印「已退出」，避免你以为程序崩了。

`break` 立刻离开循环，不再问条件：

```python
n = 0
while True:
    n = n + 1
    if n == 2:
        break
    print(n)
print("出来了")
```

预期：

```text
1
出来了
```

`n` 变成 2 时离开，所以不会打印 2。

`continue` 跳过这一轮剩下的行，回到条件那里：

```python
for text in ["", "耳机", "充电器"]:
    if text == "":
        continue
    print(text)
```

预期：

```text
耳机
充电器
```

空字符串那一轮，`print` 被跳过了。客服脚本对空回车用的就是 `continue`：不要发送，回去再等一行。如果这里误写成 `return`，顾客多按一次回车，整个程序就结束了。

`return` 比 `break` 更彻底。它离开的是整个函数，循环当然也结束。客服的「退出」用 `return`，因为退出时 `main` 也该结束，没有循环后面的步骤要做。

## 常见错误

`while True` 里面既没有 `break` 也没有 `return`，也没有会改变条件的赋值。程序看起来卡死，CPU 风扇可能转快。先 Ctrl+C。然后检查有没有一条路能离开。

把「退出」写成 `continue`。顾客永远退不出去，只会无限再看到 `你：`。

在还没学 `input` 时就写一个没有输出的 `while True`。你看不到任何变化，很难判断它是在等还是在空转。我们的循环每一轮都会 `input`，至少提示符 `你：` 还在，说明它活着并且在等你。

## 练习

1. 用 `while` 打印 1 和 2 后停止。可以用 `break`，也可以用条件 `n < 3`。写出一种即可。
2. 空行应该 `continue` 还是 `return`？退出命令呢？
3. `for` 和 `while True` 各适合客服脚本的哪一部分：打印历史列表，还是一直等下一句？

## 答案

1. 例如 `n = 0`，`while n < 2:`，里面 `n = n + 1` 和 `print(n)`。输出两行 `1` 和 `2`。
2. 空行用 `continue`，柜台还要营业。退出用 `return`（或 `break` 后再结束函数）。我们的代码用 `return`。
3. 打印已经在列表里的历史用 `for`，张数是已知的。一直等顾客下一句用 `while True`，句数未知。
