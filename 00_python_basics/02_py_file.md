# `.py` 文件，以及 `python 文件.py` 在做什么

`01_hello_llm.py` 就是一个文本文件，扩展名 `.py` 表示「请用 Python 来读」。它不是一个已经编译好的按钮，也不是 Word 文档。

## 先用一句人话

你用 `python 某个文件.py` 时，Python 从文件第一行读到最后一行，读到能执行的句子就立刻做。读完，程序就结束，除非代码里写了循环，让它停下来等你。

## 打个比方

`.py` 文件是一张菜谱。`python 菜谱.py` 是请厨师按纸上的顺序做菜。厨师不会因为菜谱躺在文件夹里就自动开做。你不喊他，纸就只是纸。

交互模式则是不拿菜谱，你说一句他做一句。提示符变成 `>>>`。

## 自己动手

下面要用 `print`。它的完整课是[下一课](03_print.md)。现在只要知道：`print` 后面括号里的文字会被显示到屏幕上。

站在项目根目录。用记事本或编辑器新建一个文件 `00_python_basics/try_hello.py`，内容只有一行：

```python
print("你好，我是一个 py 文件")
```

保存。在项目根目录运行：

```bash
python 00_python_basics/try_hello.py
```

如果 `python` 不存在，试 `python3`。本仓库其余地方写 `python` 时，都换成你这台电脑上能用的那个。

你应该看到：

```text
你好，我是一个 py 文件
```

然后回到终端提示符。程序已经结束，它不会继续等你。

再打开交互模式：

```bash
python
```

你会看到 `>>>`。依次输入（每行回车）：

```text
>>> print("这句没有写进文件")
这句没有写进文件
>>> 1 + 1
2
>>> exit()
```

`exit()` 离开交互模式。`1 + 1` 没写 `print` 也显示了 `2`，这只在交互模式里如此：它会把表达式的结果回显出来。写在 `.py` 文件里的 `1 + 1` 什么都不会显示，因为文件不会自动回显。想在文件里看见结果，就要 `print`。

做完可以把 `try_hello.py` 删掉。它不是项目的正式脚本。

## 运行正式脚本和这个实验是同一件事

在项目根目录执行：

```bash
python stage0_basics/01_hello_llm.py
```

意思就是：请 Python 从 `01_hello_llm.py` 的第一行读到最后一行。还没有密钥时，它会中文说明后结束。那也是「文件被运行了」，不是「文件打不开」。

Python 读文件时：

- 空行跳过。
- `#` 后面的注释跳过（下一课）。
- 其余句子从上到下执行。
- 函数体（`def` 下面缩进的那些行）在读到 `def` 时只是被记住，要等有人调用才执行。这件事到[函数课](11_functions.md)再展开。现在只要知道：文件不是每一行都在「读到的那一瞬间」做事，但顺序仍然是从上到下。

## 常见错误

文件名打错：

```text
python: can't open file '.../01_hello.py': [Errno 2] No such file or directory
```

Python 还没开始读内容，因为磁盘上没有这个文件。用 `ls stage0_basics` 核对名字。我们的文件叫 `01_hello_llm.py`，不是 `01_hello.py`。

把 Python 代码直接贴进终端、但还没进入 `>>>`：

```text
print("你好")
print你好: command not found
```

或者 PowerShell 说找不到命令。终端听不懂 Python。要先运行 `python` 看到 `>>>`，或者把代码放进 `.py` 文件再用 `python 文件.py`。

忘记保存文件就运行：屏幕上是上一次保存的内容。编辑器里看见了，磁盘上还是旧的。

## 练习

1. 写一个只含 `print("星河")` 的文件并运行。预期屏幕上有什么？运行结束后程序还在等你打字吗？
2. 在交互模式里输入 `2 * 3`，不写 `print`。你会看到什么？同样这行放进 `.py` 文件且不写 `print`，运行后为什么常常「什么都没有」？
3. `python stage0_basics/01_hello_llm.py` 里，谁是程序，谁是菜谱？

## 答案

1. 屏幕上有一行 `星河`。程序随即结束，不再等你，因为文件里没有 `input` 或无限循环。
2. 交互模式会回显 `6`。`.py` 文件不会自动回显表达式，所以看起来像没运行。其实运行了，只是没有让它显示。
3. `python` 是厨师（解释器，真正干活的程序）。`.py` 文件是菜谱。命令的意思是让这个厨师读那张菜谱。
