# split 和 join：切开，再粘回去

[字符串](07_strings.md) 讲过引号和 f-string。[`strip`](19_input.md) 会去掉首尾空白。阶段 4 还要把一整篇说明按空行切开，再把好几段用空行粘回一条提示。

阶段 4 用在 [切块](../stage4_rag/docs/02_chunk.md) 的 `split("\n\n")`，以及 [拼提示](../stage4_rag/docs/04_prompt.md) 的 `"\n\n".join(...)`。

## 先用一句人话

`split` 是按你给的刀口把一条字符串切成列表。`join` 是用一条字符串当胶水，把列表粘成一条字符串。胶水写在前面，不是写在列表后面。

## 打个比方

一张长收据上，两段话之间空了一行。`split("\n\n")` 沿着那条空行撕开，变成两张小票。`"\n\n".join(小票列表)` 再按同样的空行贴回去。撕开和贴上用的是同一条缝。

## 自己动手

```python
text = "第一段\n\n第二段"
parts = text.split("\n\n")
print(parts)
print(" | ".join(parts))
```

预期：

```text
['第一段', '第二段']
第一段 | 第二段
```

`\n\n` 是两个换行，也就是中间那一整个空行。切完之后，刀口本身不留在任何一段里。

只切一行里的字：

```python
print("未满99元".split("99"))
```

预期：

```text
['未满', '元']
```

`join` 的胶水可以是空字符串。`" ".join(["100", "积分"])` 得到 `100 积分`，中间是一个空格。

切完常常要再 `strip`。`"  第二段  ".strip()` 得到 `第二段`。`strip` 只动首尾，中间的空格还在。那是第 19 课。

## 常见错误

写成 `parts.join(" | ")`。列表没有 `join`。胶水才有：

```text
AttributeError: 'list' object has no attribute 'join'
```

要写 `" | ".join(parts)`。

`split` 之后以为得到的仍是一条字符串。它是列表。要一段一段看，用 `for`。

刀口写错。`"第一段\n\n第二段".split("\n")` 会在每一个换行处都切，空行会变成列表里的空字符串。阶段 4 按空行切，刀口是 `"\n\n"`。

## 练习

1. `"a|b|c".split("|")` 得到什么？
2. `"\n".join(["甲", "乙"])` 打印出来是一行还是两行？
3. 为什么 `join` 写在胶水字符串上，而不是写在列表上？

## 答案

1. `['a', 'b', 'c']`。
2. 两行。胶水是换行，所以「甲」和「乙」各占一行。
3. `join` 是字符串的方法。列表自己不知道你想用什么把各项粘起来，胶水知道。
