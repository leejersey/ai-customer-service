# 正则替换：找出全部，再按分组换掉

[第 25 课](25_regex.md) 用 `search` 找第一处，用 `group` 取出订单号。阶段 6 要处理的是一句里可能有好几个号码，而且要换成打码，不是只打印第一个。

阶段 6 用在 [打码](../stage6_compliance/docs/03_pii.md) 的 `mask_text`。

## 先用一句人话

`findall` 把每一处都收进列表。`sub` 把每一处换成你给的新文本。新文本可以是一个固定的词，也可以是一个函数：函数拿到这一处匹配，自己决定换成什么。

## 打个比方

`search` 是在一页信里用笔圈出第一处电话。`findall` 是把所有电话都抄到一张清单。`sub` 是拿修正液盖住电话，再写上「已省略」或只留下前三位。

## 自己动手

没有分组时，`findall` 的每一项是整段：

```python
import re

text = "订单 10086 和 20001"
print(re.findall(r"\d+", text))
```

预期：

```text
['10086', '20001']
```

有分组时，`findall` 交回的是分组，不是整段。这和 `search` 之后自己点 `group` 不一样：

```python
phone = re.compile(r"(1[3-9]\d)\d{4}(\d{4})")
print(re.findall(phone, "手机13800138000"))
print(phone.sub(r"\1****\2", "手机13800138000"))
```

预期：

```text
[('138', '8000')]
手机138****8000
```

`\1` 是第一对圆括号。替换字符串里用 `\1`，在函数里用 `match.group(1)`。阶段 6 用函数，是因为邮箱和卡号的星号个数要随长度变。

```python
def hide(match):
    return match.group(1) + "****" + match.group(2)

print(phone.sub(hide, "手机13800138000，备用13912345678"))
```

预期：

```text
手机138****8000，备用139****5678
```

`sub` 的第二个参数这里是函数本身，没有加括号。加了括号就是先调用一次，交进去的就不是函数了。函数当参数的完整课是 [第 62 课](62_pass_function.md)。

## 常见错误

`findall` 有分组时，以为列表里是整段号码。你拿到的是 `('138', '8000')` 这种元组。整段要用 `finditer`，再对每一处取 `group(0)`。

`sub` 写成 `text.sub(...)`。`sub` 在正则对象或 `re` 上，不在字符串上。字符串自己的 `replace` 只能换固定的词。

忘了原始字符串，把 `\d` 写成普通字符串里的转义。模式仍用 r 开头的引号。第 25 课说过这件事。

替换顺序随便放。18 位身份证也像一长串卡号。先换形状更明确的，再换更宽的。

## 练习

1. `"a@ex.com 和 b@ex.com"` 里有两个邮箱。用 `findall` 时，模式如果写成 `(\w)@(\w+\.\w+)`，列表里的每一项长什么样？
2. 为什么 `sub` 的第二个参数有时不写引号里的字，而写一个函数名？
3. `search` 和 `findall` 对「一句里有两个手机号」各会怎样？

## 答案

1. `[('a', 'ex.com'), ('b', 'ex.com')]`。有分组时，每一项是分组组成的元组。
2. 每一处匹配要留的前后缀不一样。函数能看见这一处的 `group`，固定的一个词做不到。
3. `search` 只给第一处。`findall` 或 `sub` 会走到每一处。
