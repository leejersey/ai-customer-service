# 阶段 0 需要下面两个库。阶段 3 再加 redis 和 fakeredis。
# 阶段 4 的检索只用标准库，不往这个文件里加包。
# 阶段 5 加 numpy、faiss-cpu，以及可选的 sentence-transformers。
# 在已经激活的虚拟环境里执行：
#     pip install -r requirements.txt
#
# openai
#   OpenAI 官方的 Python SDK。DeepSeek 提供了与它兼容的聊天接口，
#   所以我们改 base_url 和密钥，就能用同一个库调用 DeepSeek。
#   本仓库使用 chat.completions（聊天补全），不使用更新的 Responses API。
#   上限写到 <4，是为了避免将来大版本改了调用方式后，pip 自动装上不兼容的版本。
#
# python-dotenv
#   从项目根目录的 .env 读取配置。密钥放在 .env 里，而不是写进 .py 文件。
#
# 阶段 2 的数据库用 Python 自带的 sqlite3，不用往这个文件里加包。
#
# redis
#   Redis 的 Python 客户端。导入名和 pip 包名都是 redis。
#   阶段 3 用它保存短期记忆。本机没启动 Redis 时，脚本会改用下面的替身。
#
# fakeredis
#   用内存假装一台 Redis，方法名和 redis 客户端一致。
#   离线演示，以及连不上本机 6379 时，用它把练习跑完。
#   它的数据随进程结束，不能代替真正的 Redis。
#
# numpy
#   阶段 5 用来装向量。FAISS 要 float32 的连续数组，不是普通列表。
#
# faiss-cpu
#   阶段 5 的向量索引。本课只用 IndexFlatIP：归一化之后，内积就是余弦。
#   包名带 cpu。不要装带 GPU 的 faiss，练习用不到显卡。
#
# sentence-transformers
#   用来在本机加载中文嵌入模型 BAAI/bge-small-zh-v1.5。
#   它会再装很大的 torch，第一次运行还会下载模型。
#   可以不装。删掉下面这一行，并设置 USE_FAKE_EMBEDDING=1，
#   阶段 5 会改用哈希二字词假向量，FAISS 的练习仍能跑完。
#   假向量对得上相同的字，对不上「退钱」和「退款」。

numpy>=1.26,<3
