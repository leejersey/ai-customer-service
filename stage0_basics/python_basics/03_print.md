# print：把结果写到屏幕上

`print` 是函数。函数这个词的完整课在后面。现在把 `print` 当成一个工具：括号里放你要给人看的东西，它就写到终端上，默认最后再换一行。

我们的脚本里，`print` 第一次出现在 `01_hello_llm.py` 显示「即将发送的消息」的地方。前面的小课已经先用它，是因为没有它你看不见例子对不对。

## 打个比方

程序在后台算完，如果不喊一声，顾客什么都看不见。`print` 就是柜台的喇叭。不算数，只负责出声。删掉 `print`，计算可能仍然做了，只是你不知道。

## 自己动手

进入交互模式（`python`，看到 `>>>`），或者把下面各段存成临时 `.py` 文件再运行。两种方式的输出应该一致。

### 1. 打印文字和打印空行

```python
print("即将发送的消息：")
print()
print("正在请求模型，请稍等……")
```

预期：

```text
即将发送的消息：

正在请求模型，请稍等……
```

中间那行是空的，因为 `print()` 什么都不给，仍然换一行。这就是 `01_hello_llm.py` 里单独一个 `print()` 的作用：把屏幕上的段落隔开。

### 2. 不换行，以及立刻显示

```python
print("模型：", end="")
print("你好")
```

预期：

```text
模型：你好
```

`end=""` 把默认的「结尾换行」换成「结尾什么都没有」。流式脚本用它，是为了让后到的几个字接在同一行，而不是每个字一行。

`flush=True` 是在说：不要把字暂时存在缓冲区，马上写到屏幕上。交互模式里不一定看得出差别。放在文件里、输出很多时，没有它，字可能攒一批才出现。

```python
print("模型：", end="", flush=True)
```

这一行本身的预期就是屏幕上出现 `模型：` 并且不换行。

### 3. 一次打印好几样，中间有空格

```python
print("条数", 3)
```

预期：

```text
条数 3
```

逗号让 `print` 在两样东西之间加一个空格。数字 `3` 不用加引号。

## 常见错误

括号没关上：

```text
SyntaxError: '(' was never closed
```

`SyntaxError` 表示这句话写法不合法，Python 拒绝开始运行后面的内容。

把要显示的字忘了加引号：

```python
print(你好)
```

```text
NameError: name '你好' is not defined
```

没有引号时，Python 以为 `你好` 是一个变量名。你还没创建这个名字，所以报错。文字要用引号，下一课字符串会细讲。变量课会讲名字。

函数名拼错：

```python
pint("你好")
```

```text
NameError: name 'pint' is not defined. Did you mean: 'print'?
```

Python 3.12 会在后面附上一句「你是不是想写 print」。那只是提示，程序仍然没有执行。不要以为它已经自动改对了。

## 练习

1. 写出能显示下面两行的代码（两行之间不要空行）：

   ```text
   小星
   在线
   ```

2. 想得到一行 `你：你好`，而且 `你：` 和 `你好` 来自两次 `print`。第二次才换行。写出这两次调用。
3. 为什么 `print("3")` 和 `print(3)` 看起来一样，却不是同一种东西？只要求用一句话回答。

## 答案

1. `print("小星")` 然后 `print("在线")`。
2. `print("你：", end="")` 然后 `print("你好")`。第一句把结尾换成空，第二句使用默认换行。
3. 带引号的是一段文字，不带引号的是数字。屏幕上看起来都是字符 3，但后面做加法时结果不同。数字课会让你看见 `"1" + "2"` 变成 `12`，而 `1 + 2` 变成 `3`。
