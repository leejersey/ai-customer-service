# 正则：按模式找一串字，而不是找一个固定词

关键词用 `in` 就够：「退款」在不在这句话里。[列表课](13_lists_dicts.md) 里已经比过 `"quit" in "我想 quit"`。订单号不是固定的那一个词，可能是 10086，也可能是 20001。要描述的是「一串数字」，这就是正则表达式。

第一次出现在 `stage1_intent/rule_intent.py` 的 `import re`。

## 打个比方

关键词是在找一个写死的门牌。正则是在找「连续四位以上的数字」，不管具体是哪几个数字。`re` 是 Python 自带的标准库，不用 pip。

## 自己动手

```python
import re

text = "订单号：10086 到哪了"
found = re.search(r"\d+", text)
print(found.group(0))
```

预期：

```text
10086
```

`re.search` 在文字里找第一处符合模式的片段。找不到时交回 `None`，不是空字符串。

```python
print(re.search(r"\d+", "没有数字") is None)
```

预期：

```text
True
```

对 `None` 调用 `.group` 会：

```text
AttributeError: 'NoneType' object has no attribute 'group'
```

所以代码要先 `if found:` 再 `group`。

## 模式里这几个符号

放在原始字符串里，引号前加 `r`。这样 `\d` 原样交给正则。

| 写法 | 意思 |
| --- | --- |
| `\d` | 一个数字 |
| `\d+` | 一个或多个数字 |
| `\d{4,}` | 至少 4 个数字 |
| `\s*` | 可有可无的空白 |
| `(?:订单号\|订单)` | 这两个词都行，括号不单独抓出来 |
| `(\d{4,})` | 抓出这段数字，稍后用 `group(1)` 拿 |

`group(0)` 是整段匹配。`group(1)` 是第一对圆括号抓到的部分。我们的订单模式用 `group(1)`，因为整段里还包括「订单号」这几个字，只要数字。

```python
import re
found = re.search(r"订单号\s*[:：]?\s*(\d{4,})", "订单号：10086")
print(found.group(0))
print(found.group(1))
```

预期：

```text
订单号：10086
10086
```

`re.compile` 是把模式先编译好，反复用。结果的 `.search` 和 `re.search` 是一件事。句子很多时，不用每次重新读那串模式。

## 常见错误

没有 `r` 时，`\d` 在普通字符串里是非法转义。Python 3.12 会警告，模式也可能和你想的不一样。订单号这种模式用 `r"..."`。

把 `search` 当成「是否包含整个句子必须全匹配」。`search` 是找到一处即可。全句都必须符合才用 `fullmatch`，阶段 1 不用。

`group(1)` 写错成 `group(0)`，会把「订单号：」也收进订单号。测试里断言的是纯数字 `10086`。

## 练习

1. 从 `"单号 20001"` 取出 `20001`。模式要求至少 4 位数字。写出 `group` 的编号。
2. `"用了 2 天"` 用 `\d{5,}` 去搜，结果是什么？为什么阶段 1 的裸数字要求至少 5 位？
3. `keyword in text` 和 `re.search` 各适合找什么？

## 答案

1. `found = re.search(r"\d{4,}", "单号 20001")`，然后 `found.group(0)`。这里没有额外的捕获括号，所以用 0。若模式写成 `单号\s*(\d{4,})`，数字在 `group(1)`。
2. `None`。`2` 只有一位，凑不满 5 位。这样就不会把「2 天」当成订单号。带「订单号」标签时我们放宽到 4 位，因为有标签，误认的可能更小。
3. 固定词语用 `in`。长度不固定的数字、可选冒号这种「形状」用正则。
