# 字符串：引号里的文字

字符串就是一串文字。`01_hello_llm.py` 里第一次把文字放进变量是：

```python
SYSTEM_PROMPT = "你是「星河数码」的客服助手。请用简体中文回答，语气礼貌，控制在两句话以内。"
```

引号不在字符串里面。它们只是告诉 Python：从这里开始是文字，到下一个同样的引号结束。

## 打个比方

引号是包装纸。顾客收到的是纸里面的礼物，不是包装纸本身。所以模型看到的系统提示里没有那对英文双引号。

## 三种引号

一对双引号或一对单引号，效果一样：

```python
print("小星")
print('小星')
```

预期两行都是：

```text
小星
```

句子里如果本身有单引号或撇号，外面就用双引号，免得提前结束。我们的中文句子用双引号包住，里面的「」是中文引号，不会和英文 `"` 打架。

三引号可以跨行。命令行客服的 `SYSTEM_PROMPT` 就是这样写的：

```python
notice = """第一行
第二行"""
print(notice)
```

预期：

```text
第一行
第二行
```

换行真的在字符串里面，不只是你在编辑器里换行好看。文件最上面的文档字符串也是三引号，只是没有放进变量、也没有 `print`。

## 换行符 `\n`

`\n` 是一个字符，意思是「在这里换行」。反斜杠不是两条线，是键盘上的 `\`。

```python
print("第一行\n第二行")
```

预期：

```text
第一行
第二行
```

`04_cli_chatbot.py` 末尾有 `print("\n已退出。")`。开头的 `\n` 是为了先换一行，避免「已退出」粘在你刚输入的那一行后面。你按 Ctrl+C 时，终端往往还停在一行的中间。

## f-string：把盒子里的值嵌进文字

名字来自引号前面的字母 `f`。花括号里写变量名，出来的是值，不是名字。

```python
index = 0
role = "system"
print(f"[{index}] {role}")
```

预期：

```text
[0] system
```

这就是 `01_hello_llm.py` 里打印消息列表那一行的写法。花括号外面的方括号只是要显示的字符。

没有花括号时，`f` 也帮不上忙：

```python
name = "小星"
print(f"你好，name")
```

预期：

```text
你好，name
```

你想要的是：

```python
print(f"你好，{name}")
```

预期：

```text
你好，小星
```

## 常见错误

引号没成对：

```text
SyntaxError: unterminated string literal
```

中文引号 `“”` 被拿来当包装纸：

```text
SyntaxError: invalid character '“' (U+201C)
```

包装纸必须是英文引号 `"` 或 `'`。中文「」可以出现在包装纸里面。

反斜杠打成了斜杠：`/n` 会原样显示成斜杠和字母 n，不会换行。

## 练习

1. 用 f-string 打印 `模型名称：deepseek-chat`。模型名放在变量 `model` 里，不要把整句都写成一个没有花括号的字符串。
2. `print("a\nb")` 是一行输出还是两行？
3. 文档字符串用三引号、却没有出现在终端里，缺了哪一步？

## 答案

1. `model = "deepseek-chat"` 然后 `print(f"模型名称：{model}")`。
2. 两行：`a` 一行，`b` 一行。
3. 没有 `print`。三引号只是把文字放在那里，不会自动显示。
